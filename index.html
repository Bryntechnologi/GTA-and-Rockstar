House rules

How scoring works

  • Correct answers earn 100 points plus a streak bonus.
  • Blitz gives you 60 seconds. The clock pauses while you read the lore.
  • Sudden Death ends on the first wrong answer.
  • Mythbuster shows four statements; one is the planted lie.
  • Full Sweep changes the whole site theme to match each question's era.

    What this is

    A partial archive, made for fun.

    FIVE STAR WANTED is a personal miscellany project, part of Brynsites. It covers what time and interest allow; it is not a complete lore database and it is updated when time allows.

    Corrections, permissions, and takedown requests go through the Brynsites contact page. No email address is published on this subdomain.

    • Independent: no ads, no store, no sponsorship.
    • Mixed sourcing: original copy plus CC BY-SA adaptations, each credited to its source.
    • Sources linked: Wikipedia and GTA Wiki links sit beside the relevant entries.

    The IP boundary

    Fan project, clearly labelled.

    Game titles, characters, locations, and related marks belong to Rockstar Games and Take-Two Interactive. This project does not claim affiliation, sponsorship, or endorsement.

    • No extracted game audio, models, textures, screenshots, or copied dialogue. Credited map artwork/routes are referenced on the atlas.
    • No official logos; the site uses inline SVG, CSS gradients, and local photos with credits.
    • Non-commercial, no ads, no store, and a visible disclaimer on every page.

    If a rights holder asks for a change, the project complies. This is a design and portfolio project, not legal advice.

    Build notes

    No framework, no build step.

    Core play is local. Optional lore, map, and radio features are progressive enhancements with fallbacks. The interesting engineering is the theme engine, deterministic seeding, accessible keyboard play, generated puzzle boards, Web Audio SFX, and the PWA shell.

    • CSS custom-property theming across eight complete era skins.
    • Date-seeded daily runs using a small deterministic RNG.
    • Three generated puzzle loops, including an atlas-driven deduction game.
    • Canvas-drawn result cards and inline SVG art with no image pipeline.
    • localStorage persistence for bests, streaks, and badges.

    Local data

    Your browser, your dossier.

    This project stores only game progress and UI preferences under fivestarwanted.* keys. There is no account, tracking pixel, or remote logging. Export a text summary or wipe everything and start fresh.
