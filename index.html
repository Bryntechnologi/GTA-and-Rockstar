    The idea

    One skeleton, eight personalities.

    The entire visual system is driven by CSS custom properties and a single data-era attribute. Switching signals swaps colors, type, corner radii, shadows, ambient SVG art, and even the sound palette.

    During a Channel Surf run, the theme follows each question. In normal play, the Auto-morph toggle in the tuner does the same. Everything else is manual.

    • Original content: all trivia, fake facts, lore notes, radio chatter, and map copy were written for this project.
    • Original visuals: inline SVG, CSS gradients, and code-drawn icons. No ripped textures, models, screenshots, or audio.
    • Zero backend: static HTML, CSS, and JavaScript. Scores and badges stay in your browser.

    Build notes

    Portfolio-shaped by design.

    No framework and no build step. Core play is local; optional lore, map, and radio features are progressive enhancements with fallbacks. The interesting engineering is the theme engine, deterministic seeding, accessible keyboard play, generated puzzle boards, the small Web Audio SFX layer, and the PWA shell.

    • CSS custom-property theming across eight complete era skins.
    • Date-seeded daily runs using a small deterministic RNG.
    • Three generated puzzle loops, including an atlas-driven deduction game.
    • Canvas-drawn PNG result cards with no image assets.
    • Optional Leaflet and MapLibre maps, lazily loaded with static fallbacks.
    • localStorage persistence for bests, streaks, seen eras, and badges.
    • Inline SVG art and synthesized audio — no binary asset pipeline.
    • Reduced-motion support and keyboard controls for trivia and Heat Grid.

    Local data

    Your browser, your dossier.

    This project stores only game progress and UI preferences under channelsurf.* keys. There is no account, tracking pixel, or remote logging.

    You can wipe everything and start fresh. Exporting a text summary is also available if you want a shareable run report.
